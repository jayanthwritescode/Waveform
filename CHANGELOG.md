# Changelog

## 1.1.0 — 4 November 2026

- Refreshed the home, navigation, playlist studio, editor and library with clearer typography, spacing, illustrated covers and a more focused create/edit/export journey.
- Added optional fine-tuning instead of showing every recommendation control at once.
- Added full-library backup and additive restore, with conflict copies and explicit preference restoration.
- Added About & privacy, source credits, practical help, app metadata and an installable-app manifest for supporting browsers.
- Added product screenshots, contribution/support guides, issue forms and automated test/build checks on Node 22 and 24.

## 1.0.0 — 3 November 2026

- Moved the existing application to a free static architecture with native JavaScript modules and local storage.
- Added live MusicBrainz discovery, an attributed offline collection, explainable context ranking and playlist editing/export.
- Preserved the historical Python application, source datasets and local user files outside the deployed app.
