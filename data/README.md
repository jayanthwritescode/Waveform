# Data status

Phase 1 includes **no downloaded dataset, audio, trained model, or listening history**.

The four entries in `frontend/js/state/catalogue.js` are fictional UI fixtures. Titles, artists, durations, and genre labels are invented and are not dataset records. The three mix concepts are illustrative and contain no generated playlists. SVG illustrations in `frontend/assets/images/` are original project artwork.

Phase 2 must document the chosen source, license and attribution requirements, permitted audio use, available features, and gaps before importing actual catalogue data. Training and playback catalogues must be distinguished when they differ. Raw and processed dataset directories are ignored by Git except for their empty placeholders.
