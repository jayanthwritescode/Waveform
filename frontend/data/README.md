# Demo fallback provenance

`fallback-tracks.json` contains 208 real metadata records selected deterministically from the previously verified source files: all eight Incompetech records and 200 FMA records, round-robin across the source primary genres. Source originals remain in root `data/catalogue/` and provenance is recorded there. Source metadata was retrieved 27 October 2026. FMA metadata is CC BY 4.0; recording licenses differ and no audio is included. Each record retains source ID, source URL and attribution. Original source duration, genre/tag, title and artist values are preserved; no energy, instrumentalness or album artwork is invented. Incompetech source identifiers are ISRCs; FMA IDs are local source identifiers, not ISRCs or MusicBrainz IDs.

This file is a reliable, limited demo fallback, never described as live API data. Genre coverage is uneven and does not guarantee every mood/artist. Waveform illustrations are placeholders rather than original album covers.
