# Getting help

## My playlist is missing

Waveform saves to the browser and site address you used. Check the same browser/profile and address first. Clearing site data or closing a private window can remove local saves. Restore a full library backup from Settings, or import a single playlist JSON in the editor.

## Search isn’t returning results

Check whether the source notice says Live, Cached or Offline collection. MusicBrainz can be temporarily unavailable or throttled. Try a broader title/artist search, clear extra filters, or use the offline collection. Some recordings do not have genre tags, durations or destination matches.

## I want to listen or transfer a playlist

Use a track’s Spotify, Apple Music or YouTube Music search link, or export CSV/Tracklist and follow the editor’s transfer instructions. Review the result at the destination. Waveform does not create a streaming playlist automatically.

## I found a bug

Use the [bug report form](https://github.com/jayanthwritescode/Waveform/issues/new/choose). Include steps, browser/device and whether you used live searches or the offline collection. Do not attach private library backups, credentials or personal information. A redacted screenshot can help.

## Deployment

See [deployment instructions](docs/DEPLOYMENT.md) for the free static-host configuration. Publish only `dist/` and verify the actual HTTPS deployment before sharing its URL as live.
